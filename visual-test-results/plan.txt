Execution matrix:

- Default rendering for every public concrete component, with empty/populated and long content where meaningful; verify text hierarchy, spacing, alignment, clipping and document overflow.
- Interactive controls: hover, visible keyboard focus, disabled, changed/selected, empty, read-only, required/invalid, native picker/open states where supported. Checkbox mixed state; radio group exclusivity; MultiSelect multiple selected and option groups.
- Details/Accordion closed/open/group behavior. Dialog nonmodal/modal/close/Escape, backdrop, long content and focus. Popover show/hide/toggle/Escape/light dismiss; Tooltip actual visibility behavior and clipping.
- Table and Tree NONE/SINGLE/MULTIPLE modes; empty data, selection changes, long labels, tree expanded/collapsed branches and leaf states. Tabs initial/switch/insert with long labels and narrow widths.
- VirtualList initial/middle/end/empty/refreshed content, jump controls, resized height/row height/viewport, row boundaries and blank gaps. No performance benchmarks.
- Graphics: every SVG primitive, Canvas initial drawing and redraw, Image loaded/alternative text. Audio/Video visible controls, ready/playing/paused/muted/seek and unavailable source if demo permits.
- Layouts at desktop/narrow width; grid columns, toolbar/button bar wrapping and spacer behavior. Status values at limits, determinate/indeterminate progress, meter thresholds, spinner/reduced motion. Light/dark color schemes if enabled by CSS.
- Component mutations: add/insert/remove/clear/detach/reinsert/dispose, text/HTML/property/class/style changes and disabled state. Screenshot visible before/after outcomes.
