# Geshra security reports

Report a suspected vulnerability through [GitHub's private vulnerability reporting](https://github.com/tehnewb/Geshra/security/advisories/new). Include the affected revision, a minimal reproduction, the observed impact, and any suggested fix. Keep credentials and personal information out of the reproduction.

Use public issues for ordinary bugs. Report vulnerabilities privately so the maintainer can investigate before details are disclosed.

Geshra is currently under development. Security fixes target the current `main` branch; a maintenance policy for released versions will be documented when releases are available.
