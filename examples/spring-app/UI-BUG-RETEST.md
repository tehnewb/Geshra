## Product corrections

- **Untouched grouped Select:** an ordered initialization command resolves the native default after nested option creation and properties finish. It chooses the first enabled option outside disabled groups, preserves explicit values/selected options, leaves native listbox/multiple behavior unchanged and silently synchronizes Java state. An initially empty dropdown defers until its first options arrive; later insertion preserves the current selection. The showcase's explicit Java workaround is removed. Older runtimes safely ignore this additive command and retain their previous behavior; they need a page reload with the updated bundle to receive the fix.
- **Tree keyboard interaction:** tree/treeitem/group semantics, expanded/selected state, one roving tab stop, visible preorder Up/Down/Home/End and Right/Left expansion/navigation. Space toggles MULTIPLE selection; Enter selects exclusively. Focus is independent of selection, NONE clears selection without disabling navigation, and SINGLE retains at most one node. Handled keys suppress native scrolling synchronously; Tab, composition and browser shortcuts are not trapped. Native focus plus row-label scroll reveal keeps long-tree endpoints visible.
- **Tree lifecycle and ownership:** already-owned nodes are rejected across trees. Detached subtrees are omitted from navigation and selection; restoring through their original parent's addNode preserves identity and logical/DOM order. Disposal removes logical and selection references without updating dead rows during recursive teardown. Roving focus falls back to a live ancestor without stealing external focus. Restored selection remains cleared; expansion and node identity are retained.
- **Tabbed keyboard/ARIA:** linked tablist/tab/tabpanel roles and IDs, selected state, one enabled tab stop, Left/Right wrap and Home/End activation, disabled-tab skipping and enablement-driven tab-stop repair. Native button Enter/Space remains available. The existing no-selected-tab initial contract is preserved until selection/activation.
- **Document title ordering:** UI.setTitle flushes earlier pending DOM/SEO mutations before its title control packet, preventing a route's earlier SEO reset from overwriting the title. The packet is released if the ordering barrier fails. The regression route deliberately has no SeoPage so it tests the real API rather than explicit route metadata.

The change adds no production dependency or benchmark claim. Generated runtime.js is rebuilt from maintained source. TableSelectionMode's unimplemented row-selection behavior remains a separate feature gap; no fake selection or full accessibility certification is claimed. Optional tree typeahead and select-all shortcuts are not implemented.
