## Shared behavior checklist

- Construction: tag/namespace, initial text/properties/attributes, empty and Unicode content, escaping.
- Component lifecycle: add/insert/move, detach/reattach identity and retained native state, clear/remove/dispose, listener cleanup and stale events.
- Server synchronization: trusted input/change/click/keyboard interactions; read-back Java values; Java assignment versus notification; rapid sequential updates.
- Enabled state: keyboard and pointer behavior, callback suppression, restored operation after enabling.
- Fields: empty/null, min/max/step, invalid input, required/read-only, form submission and validation, select unknown values, optgroups, multiple values, radio grouping.
- Overlays: details toggle, modal/nonmodal dialog, close return value, Escape/cancel, popover show/hide/toggle/light dismissal, focus behavior.
- Table: headings, object/text rows, zero rows, append/clear/repopulate, configured selection modes; distinguish exposed-but-unimplemented APIs.
- Tree: root/children, expand/collapse, NONE/SINGLE/MULTIPLE, Ctrl toggle and Shift range, changing values and selection policy.
- Tabs: initial selection, pointer/keyboard, insertion order, boundaries and empty tabs, retained content state.
- Virtual list: empty/single/large data, first/last/bounds, row height/overscan/height changes, source replacement/refresh/key stability, trusted wheel and keyboard scroll, edit/focus retention, reconnect/dispose.
- Media/graphics: actual image loading/alternative text, audio/video play/pause/mute/seek, Canvas pixels, SVG namespace/shape updates; capture failed requests.
- Files/navigation: real uploader callback bytes/name/type, limits/error/empty where supported; downloads only if actual API exists; links and routes.
- Runtime diagnostics: console/page errors, failed requests, disconnect/reconnect and observable server callback outcomes.
